# Paper Trail: fifteen questions to rehearse

These answers describe the supplied implementation and the local Hemanth candidate; they do not certify an untested deployment. See [current validation](VALIDATION_CURRENT.md) before quoting results.

1. **What is the differentiator?** We connect explainable reading priority, exact source passages, guided study, claim decisions and citation disclosure in one student workflow. Competitive superiority is a hypothesis to evaluate, not an established result.
2. **What does Confirmed mean?** The reference passes the implemented metadata comparisons and a second registry supplies matching identity evidence. This does not prove that the research findings are true or that two registries are independent of shared upstream errors.
3. **What happens when OpenAlex is absent or disagrees?** The result stays incomplete with a visible receipt and reason. Another version of the same paper with a different DOI is not silently treated as the requested identity.
4. **Can AI approve a source?** Approval belongs to the student; AI outputs do not set the keys or reference verdict. SAMPLE receipts are blocked from citation even if a written exception is supplied.
5. **Can a flagged source ever be cited?** The existing product permits eligible live sources to be kept with an explicit written reason, and exports carry that exception. The exception does not turn a warning into a confirmation or establish scientific validity.
6. **How are papers ranked?** Visible presets weight topic terms, publication age and metadata availability, with separate groups for matched, incomplete and warning receipts. Citation counts confer no ranking bonus, and the score is a heuristic reading aid rather than a quality grade.
7. **Does Study studio certify understanding?** It records the student's explanation, exact passage, critical reflection and self-assessed recall, tied to the exact source text. It neither grants citation approval nor proves mastery, and its educational effect still needs independent evaluation.
8. **What can run without a generative-AI key?** Registry retrieval, deterministic checking, extractive reading, ranking, guided study and citation tools have code-based paths. Retrieval still needs network access, while uncached models, citation assets and routes may also need preparation.
9. **Which open tools are used?** The existing stack includes Meta's React, Mozilla PDF.js, Transformers.js with ONNX Runtime, and a Microsoft DeBERTa support model; Gemini and Groq are optional server providers. Their presence is not proof of superior results, and free quotas, model availability and provider terms need checking before the demonstration.
10. **Does the system detect all plagiarism?** Draft checks compare the student's text with the available library and flag passages for review. They cannot inspect the entire web, establish intent or certify originality.
11. **What leaves the browser?** Registry queries and selected optional AI task inputs leave the browser, while uploaded PDFs are parsed locally. Account backups are encrypted in the browser, which protects the saved copy but does not conceal task input deliberately sent to an AI provider.
12. **Can a student manipulate the log or AI level?** The level is a student declaration, and the log checks internal hash, project and sequence consistency. Removed tails or rebuilt chains can evade detection without an external checkpoint, so the system is tamper-evident rather than tamper-proof.
13. **What does the current evidence establish?** The local dependency-free suite passes 27 tests, and the recorded Lab replay exposes 24 cases including ten unresolved outcomes. Full locked-dependency verification, app browser tests, live rehearsal and comparative benchmarks are still pending.
14. **What will you do if the demo network fails?** Show the actual failed receipt and switch only to a clearly announced prepared project or SAMPLE replay. Never present recorded results, simulated timing or a fallback model response as a fresh successful live run.
15. **Who is accountable, and is this allowed by the school?** The student remains accountable for source decisions, writing and disclosure, subject to the instructor's assessment-specific requirements. The public SP Jain policy and APA contribution guidance inform the interface but do not constitute permission to use AI in every assessment.

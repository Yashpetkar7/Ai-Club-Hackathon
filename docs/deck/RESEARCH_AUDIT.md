# Research report accuracy audit

**Reviewed:** 24 November 2026, Asia/Dubai.  
**Report:** *Paper Trail — Deep Research and Competitive Strategy Report*.  
**Code baseline inspected:** `723523c91b2cdcf26b8b9cbdf98e4facfc160df5`.  
**Scope:** the recovered report text, relevant repository code, and the primary sources linked below. This is a source and code audit; it is not a live comparative product benchmark or an independent replication of the cited research studies. Test outcomes belong in the implementation handover, not in this document unless an actual run is recorded.

## Decision

Keep the report's central recommendation: finish a coherent student integrity workflow, with inspectable evidence and visible limitations. Correct its policy-version warning and its claims about enforced export, outage handling, AI functionality and log completeness. Treat the proposed advantage as a hypothesis to demonstrate, not established superiority or uniqueness.

The report already qualifies many vendor counts and trials appropriately. The changes below preserve those qualifications and tighten places where a design intention was described as an enforced property.

That does not authorize deleting runtime event metadata: if a student actually uses a tool through Paper Trail and its event records tool/version information, the product's disclosure must preserve it. [Runtime event fields](../../src/core/contracts.ts).
- **APA slot — user input required:** `[Hemanth to supply the required items after reading APA's AI contribution statement guide.]` No checklist, compliance claim, or invented requirement is supplied here.
- **Lab evidence:** no live accuracy, catch-rate, accessibility or benchmark result is asserted by this audit. Keep every predeclared case, list every miss, retain uncertainty in denominators, and visibly label replayed/recorded examples SAMPLE. [Brief](../team/HEMANTH.md), [replay](../../tests/unit/replay.ts).
- **Cancellation:** invalidating the active run can stop scheduling and reject stale UI updates; it does not prove in-flight network requests were aborted. The current shared registry interface has no caller-supplied cancellation signal. [Check](../../src/pages/Check.tsx), [Find](../../src/pages/Find.tsx), [registry interface](../../src/core/verify/verdict.ts).
- **Scope of this recheck:** the report's citation-checker benchmark counts and all research-study results were not independently replicated here. Their study populations and dates must remain attached if used; deck numbers remain limited to the brief's approved facts or actual recorded tests.
- **Build boundary:** shared-code findings are requests for their owners, not permission for Hemanth to change contracts, verifier, policy, storage or other pages. Priorities and acceptance tests are in [Team ideas](TEAM_IDEAS.md).
